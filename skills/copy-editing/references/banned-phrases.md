# Banned phrases

The single list. If you are asking "can I write this", the answer is here.

Scope is **word and phrase level**. Two neighbours cover the rest:

- Sentence shape, rhythm and rhetorical structure: the `stop-slop` skill.
- General plain-English simplification, 268 swaps: `plain-english-alternatives.md`
  beside this file.

Nothing below is a rule of English. These are house calls, and a few are calibrated to
how language models wrote in 2025. See **Shelf life** at the foot.

## The one hard rule

**No em dashes.** Not "sparingly", not "for deliberate emphasis". None.

| Instead of | Write |
|---|---|
| The results—which surprised us—showed… | The results, which surprised us, showed… |
| This approach—unlike the others—allows… | This approach, unlike the others, allows… |
| Skills—written and verbal—are essential | Skills (written and verbal) are essential |

Commas for parenthetical asides, colons to introduce, parentheses for supplementary
detail. Every em dash has one of those three as a replacement.

## Never open with

- "In today's fast-paced world…" / "In today's digital age…" / "In today's [anything]"
- "In an era of…" / "In the ever-evolving landscape of…" / "In the realm of…"
- "It's important to note that…"
- "Let's delve into…"
- "Imagine a world where…"

## Never transition with

- "That being said…"
- "With that in mind…"
- "It's worth noting that…" / "It's worth mentioning that…"
- "At its core…"
- "To put it simply…" / "In essence…"
- "This begs the question…"
- "When it comes to the realm of…"
- "Furthermore" / "Moreover" / "Notwithstanding"

## Never close with

- "In conclusion…" / "To sum up…" / "In the final analysis…"
- "All things considered…" / "At the end of the day…"
- "By [doing X], you can [achieve Y]…"

## Never structure as

- "Whether you're a X, Y, or Z…"
- "It's not just X, it's also Y…"
- "Think of X as [elaborate metaphor]…"
- A sentence opening with "By" plus a gerund: "By understanding X, you can Y…"

## Swap these words

### Verbs

| Banned | Write |
|---|---|
| delve (into) | explore, examine, investigate, look at |
| leverage | use, apply, draw on |
| utilise / utilize | use |
| optimise / optimize | improve, refine |
| facilitate | help, enable, support |
| foster | encourage, support, develop |
| bolster | strengthen, support, reinforce |
| underscore | emphasise, highlight, stress |
| unveil | reveal, show, introduce |
| navigate | manage, handle, work through |
| streamline | simplify |
| enhance | improve, strengthen |
| endeavour | try, attempt |
| ascertain | find out, determine, establish |
| elucidate | explain, clarify |

### Adjectives

| Banned | Write |
|---|---|
| robust | strong, reliable, thorough, solid |
| comprehensive | complete, thorough, full, detailed |
| pivotal / crucial / vital | key, important, essential |
| transformative | significant, major |
| cutting-edge / groundbreaking / innovative | new, original, advanced |
| seamless | smooth, easy, effortless |
| intricate / nuanced | complex, subtle, detailed |
| multifaceted | varied, diverse |

### Academic tells

| Banned | Write |
|---|---|
| shed light on | clarify, explain, reveal |
| pave the way for | enable, allow, make possible |
| a myriad of / a plethora of | many, numerous, several |
| paramount | essential, critical |
| pertaining to / with respect to / in terms of | about, regarding, for |
| prior to | before |
| subsequent to | after |
| in light of | because of, given |
| the fact that | that, or rewrite the sentence |

## Delete these outright

Filler and empty intensifiers. Cut them, or replace with something specific:

absolutely · actually · basically · certainly · clearly · definitely · essentially ·
extremely · fundamentally · incredibly · interestingly · naturally · obviously · quite ·
really · significantly · simply · surely · truly · ultimately · undoubtedly · very

Also the lazy extremes, which claim authority the sentence has not earned:

every · always · never · everyone · everybody · nobody

## Self-check

1. Read it aloud. Anything you would not say to a colleague, rewrite.
2. Search the document for `—`. Expect zero.
3. Search for the filler list. Each hit is a deletion unless it earns its place.
4. Look for clusters. Three banned words in a paragraph means rewrite the paragraph,
   not the words.

## Shelf life

The AI-tell items are calibrated to how models wrote in **2025**. "Delve" became a signal
because of one era of output, not because it is a bad word. Re-check this section yearly:
tells move, and a list that is stale reads as superstition.
